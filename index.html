02 / 回合控制台

一回合，四個節點

主階段沒有固定行動順序；每次進攻都會插入完整戰鬥流程，結算完才回到主階段。

01

READY / START / DRAW

把整個陣線重新喚醒

  1. 重置：將自己場上所有橫置卡轉為就緒，觸發「On Ready」。
  2. 回合開始：結算寫有「回合開始」的持續或被動效果。
  3. 抽牌：抽 1 張；先手玩家的第一回合跳過此步。
就緒單位才能執行一般進攻、撤退或需要橫置的能力。
02

MAIN PHASE

依戰況自由安排每一手

  • 擴充供應每回合一次，蓋牌後可補抽 1 張。
  • 打出卡牌橫置等量供應支付費用。
  • 啟動能力支付冒號前列出的所有代價。
  • 進攻／撤退進入戰區會立刻開戰。
這些行動可用任何順序進行，只要卡牌、費用與場面都合法。
03

COMBAT INSERT

每次進攻都完整走過五步

  1. 1能力計算加成；On Attack 與 On Defend 進堆疊。
  2. 2反制防守方優先開啟回應，後進先出。
  3. 3確認若攻守任一方失效，跳過傷害。
  4. 4傷害雙方同時造成 ATK；僅就緒守軍可還擊。
  5. 5結算進攻者獨存便佔領；雙方存活則退回原處。
戰鬥結束後回到主階段，你可以繼續行動或再發起進攻。
04

END PHASE

先計分，再清理戰場

  1. 計分：累加各戰區友方單位的影響力，之後觸發 On Score。
  2. 結束效果：結算 Turn End，再移除所有單位的暫時傷害。
  3. 手牌上限：超過 10 張則棄到 10 張。
  4. 勝負確認：若你的 VP 至少 20，立即獲勝。
計分不是選擇性動作；0 影響力仍算完成計分並可觸發 On Score。

03 / 卡牌識別

四種牌，四種落點

辨認牌種就能知道它會留在哪裡。下列為官方卡圖範例；點擊卡圖可放大閱讀。

UNIT / 單位

佔領與戰鬥的主體

打出時通常橫置進入預備區。生命降至 0 就被摧毀；就緒時可進攻、撤退或啟動單位行動。

預備區 → 戰區

TACTIC / 戰術

一次性改變局面

效果結算後送入墓地。帶有 Counter 的戰術可在戰鬥反制步驟回應，也可於自己的主階段正常打出。

立即結算 → 墓地

TERRITORY / 領土

直接改造一座戰區

可付費正面打出，也可免費蓋放，之後於主階段或作為反制支付費用翻開。每位玩家每區限一張友方領土。

直接放入戰區

ITEM / 物品

把單位調校成關鍵棋子

裝備到自己預備區內的單位，效果立即套用。不能主動卸下；單位離開戰場時，所附物品會被摧毀。

附加於預備區單位

RENOWNED / 聞名

同名角色，只能有一位在你控制之下。

若同名聞名單位或領土已由你控制，便不能再正常打出；原卡離場後，才可打出另一張。

TOKEN / 衍生物

由效果建立，只在戰場上存在。

  • 供應費用永遠是 0，建立時一律為橫置狀態。
  • 離開預備區或戰區後便從遊戲消失，可放回衍生物堆。

05 / 規則速查

開局、區域與容易漏掉的規則

以下整理自官方 Comprehensive Ruleset。遇到卡牌特例或版本更新時，仍以官方英文規則為準。

01開局設置
  1. 將 3 個共享戰區排成一直線。
  2. 隨機決定選擇先手或後手的玩家。
  3. 各抽 6 張；可將全部起手洗回並重抽 6 張，整局限一次。
  4. 各把 1 張手牌蓋放為起始供應，再抽 1 張替代。
  5. 先手開始，並跳過自己的第一個抽牌步驟。
02場上區域
  • 戰場：預備區加上三個戰區。
  • 戰區：雙方共享；戰鬥結束後每區只能留下 1 個駐守單位，交戰時會短暫同時有進攻者與防守者。
  • 非戰場區：牌庫、手牌、供應區、墓地與放逐區。
  • 資訊：戰區／預備區／墓地公開；手牌與供應僅持有者可看；牌庫為隱藏。
03反制堆疊
  • 有守軍時，由防守方決定是否先打出反制。
  • 反制包含 Counter 戰術、翻開蓋伏領土、Swift 單位，以及可支付代價的啟動能力。
  • 每次新回應疊在最上方，最後加入者最先結算。
  • 目標若在結算時失效，該目標部分不產生效果，其餘堆疊仍繼續結算。
04傷害與離場
  • 戰鬥傷害同時造成；生命降至 0 的單位被摧毀。
  • 未死亡單位保留本回合傷害，到自己結束階段才重置。
  • 卡牌離開戰場或進入私人區域時，移除獲得的能力與計數物並恢復原狀。
  • 衍生物離開戰場後不再存在。
05牌庫耗盡

若你在抽牌階段因牌庫沒有卡而無法抽牌，對手獲得 3 VP。這不是立即敗北，勝負仍以先達 20 VP 判定。

GLOSSARY

核心術語

Ready / 就緒

直向狀態；能執行一般單位行動或支付橫置代價。

Exhausted / 橫置

橫向狀態；單位通常無法進攻、撤退或以戰鬥傷害還擊。

Influence / 影響力

回合結束時，駐守戰區單位為你提供的 VP 數值。

Staging Area / 預備區

單位與裝備入場的公開區域，也是單位進攻的起點。

Counter Stack / 反制堆疊

戰鬥中雙方加入回應的序列，採後進先出結算。

Battlefield / 戰場

預備區與三個戰區的總稱，不包含手牌、供應或墓地。

Floating Supply / 浮動供應

橫置供應後產生的暫存資源；每位玩家回合結束時歸零。

Renowned / 聞名

具獨特名稱的卡；同名卡不能同時由同一玩家控制。

找不到相符術語。

勝利

先達 20 VP

結束階段按駐守單位的影響力計分；無法於抽牌階段抽牌時，對手 +3 VP。

開局

起手 6、供應 1

一次全手重抽機會；各蓋 1 張為供應並補抽。先手首回合不抽牌。

主階段

自由排序行動

擴充供應、出牌、啟動能力、進攻與撤退；每次進攻先完整結算戰鬥。

戰鬥

能力 → 反制 → 確認 → 傷害 → 結算

傷害同時造成；反制後進先出。雙方存活時，進攻者回到原處。

結束

計分 → 效果 → 清傷 → 手牌

手牌超過 10 張則棄到 10；最後確認是否已達 20 VP。

組牌

50+ / 同名 3 / 陣營 2
